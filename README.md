# Aren John Esoen - Software Engineering Portfolio

> **Build. Deploy. Iterate.**

This repository contains the source code for my professional portfolio. Designed around a Brutalist/Telemetry aesthetic — sharp borders, hard shadows, bracketed labels, and data-driven layouts — with a focus on clean engineering and smooth performance.

## 🚀 Features
- **Brutalist Telemetry Aesthetic**: Custom-built kinetic typography, CRT scanline effects, hard-offset shadows, and aggressive interactive hover states.
- **Cinematic Boot Sequence**: A dynamic, pure CSS/JS terminal preloader featuring a blinking block cursor and ASCII progress generation.
- **System Dashboard Navigation**: A responsive, auto-shrinking top bar with Intersection Observer logic that tracks the active viewing section like a live monitor.
- **100% Fully Responsive**: Fluid typography clamps and custom mobile overlays ensure a flawless layout from ultra-wide 4K monitors down to 320px mobile screens.
- **Light / Dark Mode**: Built-in, performant theme toggling logic using CSS variables.

## 🛠️ Tech Stack
- **Framework**: [Vite](https://vitejs.dev/) for blazing-fast local development and optimized production bundling.
- **Core**: Vanilla JavaScript (ES6+), semantic HTML5, and advanced custom CSS3 (CSS Grid, Flexbox, Clamped Typography, CSS Variables).
- **Libraries**: [Lenis](https://lenis.studiofreight.com/) for smooth native scrolling, [@vercel/analytics](https://vercel.com/docs/analytics) and [@vercel/speed-insights](https://vercel.com/docs/speed-insights) for production observability.

## 💻 Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rnjhnd/web-portfolio.git
   cd web-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
